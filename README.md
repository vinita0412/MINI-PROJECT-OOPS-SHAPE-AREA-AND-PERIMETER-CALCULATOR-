# Shape Area & Perimeter Calculator (C++)

A simple C++ mini-project to calculate the area and perimeter of different shapes like Circle, Rectangle, and Triangle using OOP concepts.

## Features
- Calculates area and perimeter of different shapes.
- Uses inheritance and virtual functions.
- Demonstrates function overriding and runtime polymorphism.
- Takes dimensions as input from the user.

## Shapes & Formulas
- **Circle:** Area = π × r², Perimeter = 2 × π × r
- **Rectangle:** Area = length × width, Perimeter = 2 × (length + width)
- **Triangle:** Area = ½ × base × height, Perimeter = side1 + side2 + side3

## Sample Input/Output

**Example 1: Rectangle**

```text
Enter length: 10
Enter width: 5

Area of Rectangle: 50
Perimeter of Rectangle: 30
```

**Example 2: Circle**

```text
Enter radius: 7

Area of Circle: 153.94
Perimeter of Circle: 43.98
```

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Virtual Functions
- Function Overriding
- Runtime Polymorphism

## How to Run

Compile the program:

```bash
g++ main.cpp -o main
```

Run it:

```bash
./main
```

*For Windows, run `main.exe` after compilation.*
